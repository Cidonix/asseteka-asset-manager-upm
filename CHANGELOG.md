# Changelog

## [1.0.4]

- Added a changelog to Unity Package Manager.
- Fixed the Changelog link to open the GitHub release history.
- Moved interrupted import actions next to the asset download controls and added a project recovery view.
- Added recovery tooltips and clarified the actions to resume an import, restore a previous version, or undo a first import.
- Replaced page navigation with a loaded asset count and Load more.
- Added Overview, Releases, and Images tabs to the asset details.
- Show a version-specific import or install action after the download is verified.

## [1.0.3] - 2026-11-20

- Made the import journal refresh automatically after a ZIP import or recovery and when you expand the section.
- Removed the manual refresh button. Resume and restore actions remain available for interrupted imports.

## [1.0.2] - 2026-11-19

- Fixed the missing README metadata error when installing the package from GitHub.

## [1.0.1] - 2026-11-19

- First public UPM release for the Windows Unity Editor.
- Added browser sign-in and access to the Asseteka library from the Editor.
- Supported ZIP and `.unitypackage` imports and installation and updates of UPM packages.
